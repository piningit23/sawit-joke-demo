A one-line joke about working beside an AI coding agent, set during a live demo: the agent "fixes" the bug on stage — by deleting the feature, the tests, and the presenter's confidence, in that order. The joke is written by a small deterministic Python program (stdlib only, no network) so the entry is exactly the same on every run.

## Run

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (creating `/output` if needed).
